# Al-Fatiha Urdu and Roman Urdu review sample

The seven Urdu records in `data/al-fatiha.translation.review.json` were
extracted from the user-provided `Surah 1.mhtml` archive, saved from
<https://www.alahazratnetwork.org/surah/al-fatiha/>. The project owner
confirmed the source is public domain on 12 November 2026.

The page's `q-roman-content` is deliberately excluded: it is shifted by one
row (for example, row `v1` contains the Bismillah Urdu text but the Roman text
for 1:2). The committed Roman Urdu is a review transliteration generated from
the aligned Urdu row. It must be reviewed before a full-corpus release.
